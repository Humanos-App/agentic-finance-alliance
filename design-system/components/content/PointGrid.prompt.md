Short points in hairline-separated columns. Use for 3–4 ideas, one line each.

```jsx
<PointGrid items={[
  { title: 'The experience', text: 'Curated and hosted in exceptional venues, so every guest has a memorable evening.' },
  { title: 'The people', text: 'Our in-house matchmaking system seats every guest among the brightest minds, with connections that last long after the dinner ends.' },
  { title: 'Worth your time', text: 'Less noise, more signal. Straight to the answers our guests came for.' },
]} />
```

Set `large` on items for the bigger "Founders / Investors / Leaders / Creators" style. `numbered` adds mono 01, 02…
